Hybrid & linear-attention models

Lesson 4 of Beyond the dense transformer

Attention compares every token with every other, so its cost grows with the square of the length. Drop the softmax, reorder one matrix product, and attention becomes an RNN with a fixed-size memory. This lesson follows that idea from 2020's linear attention to today's delta-rule layers, and explains why the models that ship mostly keep a few ordinary attention layers in the mix.

By the end you can

  • Derive linear attention from the kernel trick $\phi(Q)\big(\phi(K)^\top V\big)$ and show why its causal form is a recurrence.
  • Compare the state updates of linear attention, RetNet, gated linear attention and DeltaNet, and compute a delta-rule update by hand.
  • Explain why hybrids keep a few full-attention layers, and estimate their memory and compute against full attention.
Prerequisites: AR.3 State-space models & Mamba (fixed-size states, parallel scans, the recall weakness). Helpful but optional: M1.1 Attention, for the softmax formula this lesson modifies.

$Q$, $K$ and $V$ are $n \times d$ matrices with $n = 8192$ and $d = 128$. Which costs fewer multiplications: $(QK^\top)V$ or $Q(K^\top V)$?

  1. $(QK^\top)V$, because it's the standard order
  2. $Q(K^\top V)$, about 64× fewer, because $K^\top V$ is only $d \times d$
  3. They cost exactly the same
  4. Neither can be computed
$QK^\top$ is $n \times n$: about $n^2 d$ multiplies. $K^\top V$ is $d \times d$: about $n d^2$. The ratio is $n/d = 64$. Softmax attention can't use this reordering, because the softmax sits between $QK^\top$ and $V$. Linear attention removes it.

A hybrid model has 48 layers: 6 full-attention layers and 42 linear-attention layers. Roughly how big is its KV cache at long context, compared with an all-attention model of the same shape?

  1. The same size
  2. Half the size
  3. Zero
  4. About 1/8 of the size, since only the 6 attention layers keep a per-token cache
Linear layers keep a fixed-size state instead of a growing cache. At long context, the 6 attention layers dominate memory: $6/48 = 1/8$.

Linear attention: drop the softmax, reorder the product

By 2020, long inputs were hitting attention's $n^2$ wall, and a wave of "efficient Transformers" tried to get around it (Linformer, Reformer, Performer and more). Katharopoulos, Vyas, Pappas & Fleuret (2020, "Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention") made the simplest move. Write softmax attention for one query $i$ as a weighted average:

$$y_i = \frac{\sum_j \mathrm{sim}(q_i, k_j)\,v_j}{\sum_j \mathrm{sim}(q_i, k_j)}, \qquad \mathrm{sim}(q, k) = e^{q^\top k / \sqrt{d}}$$

Now replace the exponential with a kernel, $\mathrm{sim}(q, k) = \phi(q)^\top \phi(k)$, where $\phi$ is a simple feature map that keeps things positive (they used $\phi(x) = \mathrm{elu}(x) + 1$). Since $\phi(q_i)$ doesn't depend on $j$, it moves outside the sums:

$$y_i = \frac{\phi(q_i)^\top \sum_j \phi(k_j)\,v_j^\top}{\phi(q_i)^\top \sum_j \phi(k_j)} \qquad\Longleftrightarrow\qquad Y \propto \phi(Q)\,\big(\phi(K)^\top V\big)$$

The sum $\sum_j \phi(k_j)v_j^\top$ is a $d \times d$ matrix computed once and shared by every query. Cost drops from about $n^2 d$ to about $n d^2$: linear in length.

The causal version is the punchline. Token $i$ may only see $j \le i$, so the shared sum becomes a running sum, which is a recurrence:

$$S_i = S_{i-1} + \phi(k_i)\,v_i^\top, \qquad z_i = z_{i-1} + \phi(k_i), \qquad y_i = \frac{\phi(q_i)^\top S_i}{\phi(q_i)^\top z_i}$$

$S_i$ ($d \times d$ per head) and $z_i$ (length $d$) are a fixed-size state: hence "Transformers are RNNs". Generation costs the same for every token, with no KV cache.

Worked example

Two-dimensional features. Token 1: $\phi(k_1) = (1, 0)$, $v_1 = (2, 1)$. Token 2: $\phi(k_2) = (0, 1)$, $v_2 = (0, 4)$. Query $\phi(q) = (1, 1)$.

  1. State: $S = \phi(k_1)v_1^\top + \phi(k_2)v_2^\top = \begin{pmatrix}2 & 1\\ 0 & 4\end{pmatrix}$, and $z = (1, 1)$.
  2. Numerator: $\phi(q)^\top S = (2, 5)$. Denominator: $\phi(q)^\top z = 2$.
  3. $y = (1, 2.5)$. Check the slow way: both similarities are $\phi(q)^\top\phi(k_j) = 1$, so $y$ is the plain average of $v_1$ and $v_2$, which is $(1, 2.5)$.

Plain linear attention trailed softmax attention on language. Two reasons: without the exponential, attention is less sharp (it can't put nearly all its weight on one token), and the state is a sum that never forgets, so after thousands of tokens it's a blur of everything.

Why can't ordinary softmax attention use the cheap order $Q(K^\top V)$?

  1. Because $V$ is too large
  2. Because matrix multiplication isn't associative
  3. Because the softmax is applied to each row of $QK^\top$ before multiplying by $V$, so $QK^\top$ must be formed first
  4. It can; it just doesn't for historical reasons
The nonlinear softmax sits between the two products. A kernel $\phi(q)^\top\phi(k)$ factorizes the similarity, which is what lets the product be regrouped.

Decay, gates and the delta rule

Since 2023, a family of layers has fixed linear attention's "never forgets" problem by changing how the state is updated. Written with a state matrix $S_t$ and $y_t = S_t^\top q_t$ (normalizers dropped, as most of these models do):

  • Linear attention (2020): $S_t = S_{t-1} + k_t v_t^\top$. Pure accumulation.
  • RetNet (Sun et al., 2023, "Retentive Network"): $S_t = \gamma\,S_{t-1} + k_t v_t^\top$, with a fixed decay $\gamma < 1$ per head, so old entries fade. It can be computed in parallel, recurrently, or chunk by chunk.
  • RWKV (Peng et al., 2023, "Reinventing RNNs for the Transformer Era"): an RNN with learned per-channel time decay; later versions made the decay depend on the input (RWKV-6, 2024) and adopted a delta-style update (RWKV-7, 2025).
  • Gated linear attention (GLA; Yang et al., 2023): $S_t = G_t \odot S_{t-1} + k_t v_t^\top$, where the gate $G_t$ is computed from the current token. Like Mamba's $\Delta_t$, the model decides what to forget. Mamba-2 (AR.3) is close to the special case of one scalar gate per head.
  • DeltaNet (Schlag, Irie & Schmidhuber, 2021; made fast to train by Yang et al., 2024): $S_t = S_{t-1} - \beta_t\,k_t\big(S_{t-1}^\top k_t - v_t\big)^\top$. Read what the memory currently returns for key $k_t$, compare with the new value $v_t$, and correct the difference, with strength $\beta_t \in [0, 1]$. This is the classic delta (Widrow–Hoff) learning rule, applied at every token.
  • Gated DeltaNet (Yang, Kautz & Hatamizadeh, 2024) combines both: a decay gate to clear old memory quickly, and the delta rule for precise overwrites.

Worked example: add versus overwrite

Two-dimensional keys and values, $S$ starts at zero. Store $v = (3, 1)$ under key $k = (1, 0)$: $S = k v^\top$, and reading with $k$ returns $S^\top k = (3, 1)$.

  1. Now store a new value $v' = (0, 2)$ under the same key. Linear attention adds: reading returns $(3, 1) + (0, 2) = (3, 3)$, a mix of old and new.
  2. Delta rule with $\beta = 1$: the error is $S^\top k - v' = (3, -1)$, and $S \leftarrow S - k\,(3, -1)$. Reading now returns exactly $(0, 2)$: the old value was overwritten.

What does the delta rule add that plain linear attention lacks?

  1. It checks what the memory already returns for a key and corrects it toward the new value, so it can overwrite instead of piling values on top of each other
  2. A softmax over all past tokens
  3. A KV cache
  4. A fixed decay that is the same for every token
Pure accumulation mixes old and new values stored under similar keys. The delta update $-\beta k(S^\top k - v)^\top$ removes the old association in proportion to the error, which is why delta-rule layers do better on recall-heavy tasks.

Hybrids: a few attention layers go a long way

However clever the update, a fixed-size state is still a compressed memory (AR.3). Full attention keeps every token, so one attention layer can look up any earlier detail exactly. The hybrid recipe: use cheap linear or SSM layers for most of the stack, and keep a few full-attention layers for retrieval. Zoology (Arora et al., 2023) traced the gap to recall, and NVIDIA's 8B comparison (Waleffe et al., 2024) found that a small share of attention layers recovers most of it. At long context, memory is dominated by the attention layers' KV cache, so a 1-in-8 hybrid needs roughly 1/8 of the cache.

Some notable hybrids (figures as reported by their makers):

  • Jamba (AI21 Labs, 2024): one attention layer per 8, the rest Mamba, plus MoE; 52B total, 12B active, 256K context, designed to fit long inputs on a single 80 GB GPU.
  • Griffin / RecurrentGemma (De et al., 2024, Google DeepMind): gated linear recurrences mixed with local (sliding-window) attention.
  • MiniMax-01 (MiniMax, Jan 2025): 7 linear ("lightning") attention layers per softmax attention layer; 456B total, 45.9B active; trained at up to 1M tokens of context.
  • Nemotron-H (NVIDIA, 2025): about 8% attention layers, the rest Mamba-2 and MLPs; reported up to 3× faster inference than similar-size Transformers.
  • Qwen3-Next (Alibaba, Sept 2025): 3 Gated DeltaNet layers per gated attention layer, 80B total, about 3B active; the Qwen3.5 family (2026) is reported to use the same 3:1 pattern.
  • Kimi Linear (Moonshot AI, Oct 2025): 3 Kimi Delta Attention layers per attention layer; reports up to 75% less KV cache and up to 6× decoding throughput at 1M context. IBM's Granite 4.0 (Oct 2025) mixes mostly Mamba-2 layers with a few attention layers.

It isn't settled. MiniMax's next model, M2 (Oct 2025), went back to full attention; its team wrote that hybrids that matched on standard benchmarks fell short on complex multi-hop reasoning at scale, and that the inference software for efficient attention was less mature. As of late 2026, hybrids are a serious, shipping option for long-context efficiency, but most frontier models still rely mainly on full attention, often with sliding windows (AR.5).

Explain like I'm 5

A class listens to a very long story. Most children keep one summary card each: when something new happens they rub out a bit and write the new part in. The card never gets bigger, so it's light to carry.

A few children keep a photo album with a picture of every single page. It gets heavy, but when the teacher asks "what was the dog's name on page 3?", they can flip straight to it.

Put a few photo-album children in a class of summary-card children and you get both: light bags, and someone who can answer exact questions.

Where it breaks: in a real model the "children" are layers stacked one after another, each passing its result to the next, and the summary card is a matrix the model learns how to update.

Why this matters in practice: when a model card mentions "linear attention", "Gated DeltaNet", "Mamba-2 layers" or a ratio like 3:1, it is trading some exact recall for a much smaller long-context memory bill and faster long generations. Check the attention-layer count to estimate KV memory, and look at long-context recall benchmarks (AR.5), not just perplexity, before relying on it for document lookup.

Why do hybrid models keep a few full-attention layers instead of going all-linear?

  1. Linear layers can't be trained in parallel
  2. Full attention can look up any earlier token exactly, which rescues the recall and copying that fixed-size states compress away
  3. Attention layers use less memory than linear layers
  4. It's required for positional encodings
The linear layers do most of the work cheaply; the few attention layers hold the full KV cache that exact retrieval needs. Their cache then dominates memory, so the attention ratio sets the bill.
Explain it back · in two or three sentences

How does dropping the softmax turn attention into an RNN, and why do production models still keep some softmax attention?

Model answer: With a kernel similarity $\phi(q)^\top\phi(k)$, attention becomes $\phi(Q)(\phi(K)^\top V)$, and in the causal case the shared sum $\sum_{j \le i}\phi(k_j)v_j^\top$ is a running state $S_i = S_{i-1} + \phi(k_i)v_i^\top$: a fixed-size recurrence with linear cost and no KV cache. Decay, gates and the delta rule make that state forget and overwrite sensibly. But any fixed-size state compresses the past, so exact recall suffers; a few full-attention layers keep the whole context available for lookups at a fraction of the KV memory.
Check yourself

Which update gives a fixed decay that is the same for every token?

  1. $S_t = S_{t-1} + k_t v_t^\top$
  2. $S_t = G_t \odot S_{t-1} + k_t v_t^\top$ with $G_t$ from the input
  3. $S_t = S_{t-1} - \beta_t k_t (S_{t-1}^\top k_t - v_t)^\top$
  4. $S_t = \gamma S_{t-1} + k_t v_t^\top$ (RetNet)
RetNet's $\gamma$ is fixed per head. GLA's gate depends on the token, plain linear attention never decays, and the delta rule corrects instead of decaying.

Interleaving with AR.3: how is Mamba-2 related to gated linear attention?

  1. They are unrelated: one is an SSM, the other is attention
  2. Mamba-2 uses softmax attention internally
  3. By state-space duality, Mamba-2 is a linear-attention-style layer with an input-dependent scalar decay per head, close to GLA with a scalar gate
  4. GLA is a mixture of experts
Mamba-2's $C$, $B$ and $x$ play the roles of query, key and value, and its $\bar A_t$ is a data-dependent decay: the same template $S_t = g_t S_{t-1} + k_t v_t^\top$.

For prefill, causal full attention costs about $2n^2 d$ FLOPs per layer and linear attention about $4 n d\,d_h$ (head size $d_h = 128$). Beyond roughly what length $n$ is linear attention cheaper?

  1. About 8 tokens

  3. About 1 million tokens

Key takeaways

  • Linear attention swaps $e^{q^\top k}$ for $\phi(q)^\top\phi(k)$, regroups to $\phi(Q)(\phi(K)^\top V)$, and in causal form becomes a recurrence with a $d \times d$ state.
  • The family differs in the state update: accumulate (linear), fixed decay (RetNet), learned decay (RWKV), input gates (GLA, Mamba-2), the delta rule (DeltaNet) or both (Gated DeltaNet).
  • Fixed-size states compress, so exact recall suffers; a few full-attention layers rescue it.
  • Hybrids (Jamba, MiniMax-01, Nemotron-H, Qwen3-Next, Kimi Linear) cut KV memory roughly in proportion to their attention ratio, though some labs (MiniMax M2) have gone back to full attention.
