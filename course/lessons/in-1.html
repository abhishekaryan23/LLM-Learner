Features & superposition

Lesson 1 of Interpretability

An LLM's billions of numbers do something useful, but nobody wrote down how. Interpretability tries to read the mechanism back out. The first surprise is that single neurons are usually the wrong thing to look at: models store ideas as directions, and they pack in far more ideas than they have neurons. That trick is called superposition.

By the end you can

  • Give three reasons to look inside a model, and explain the difference between a neuron and a feature.
  • State the linear representation hypothesis and read a feature from an activation with a dot product.
  • Explain superposition: why sparse features let a network store more features than dimensions, and what it costs.
Prerequisites: M1.4 The decoder-only transformer (layers, the residual stream, activations) and P1.1 Vectors & dot products (dot products, cosine similarity, perpendicular vectors). Helpful but optional: P3.4 Embeddings, for word vectors.
Warm-up · guess before you learn

Guess first. A wrong guess now makes the right answer stick.

Researchers look at one neuron in an image model and find it fires strongly for cat faces, for the fronts of cars and for cat legs. What's the most likely explanation?

  1. The model is broken and needs retraining
  2. The model thinks cats and cars are the same thing
  3. The neuron helps represent several unrelated features at once, because the model stores more features than it has neurons
  4. It's a measurement error; neurons always mean exactly one thing
That neuron is real (Olah et al., 2020). Neurons like it are called polysemantic, and the leading explanation is superposition: features are spread across many neurons, and each neuron takes part in several features.

Pick two random directions in a 10,000-dimensional space. Roughly what is the angle between them?

  1. About 45°
  2. Very close to 90°
  3. Close to 0°: random vectors point the same way
  4. Anything from 0° to 180° is equally likely
In high dimensions, random directions are almost perpendicular: their cosine is typically within about $\pm 0.01$ of zero. That spare "almost-perpendicular room" is what superposition exploits.

Why look inside, and what to look for

For most of deep learning's history, trained networks were treated as black boxes: measure accuracy on a test set and move on. Researchers started opening them up early. Zeiler & Fergus (2014) visualised what each layer of an image classifier responded to, and Chris Olah and colleagues at Google and OpenAI built a whole research programme on it in the journal Distill (Feature Visualization, 2017; "Zoom In", 2020). From 2021, Anthropic's Transformer Circuits thread (Elhage et al., 2021, "A Mathematical Framework for Transformer Circuits") brought the same approach to language models. The goal of this mechanistic interpretability is to reverse-engineer the algorithm a network learned, the way you might decompile a program.

Three reasons people care:

  • Debugging. When a model gives a wrong or biased answer, behavioural tests (M4) tell you that it failed. Looking inside can tell you why: which internal fact or shortcut it used.
  • Safety. A model could behave well on every test you thought of and still carry a capability or goal you'd want to know about. Reading internal states is one of the few ways to check what a model "knows" beyond what it says.
  • Science. LLMs are a new kind of object. How do they store facts, do arithmetic, plan a rhyme? Interpretability is how we find out.

So what should you look at? The obvious unit is the neuron: one number in an activation vector, such as one output of an MLP layer (M1.4). A feature is different: it's a property of the input that the model represents internally, like "this text is in French", "this token is inside a URL" or "the subject is a sports team". The hopeful picture is one neuron, one feature (a monosemantic neuron). Some neurons really do look like that. Many don't. In the InceptionV1 image model, neuron 4e:55 fires for cat faces, for the fronts of cars and for cat legs (Olah et al., 2020). Neurons that respond to several unrelated things are called polysemantic, and in language models they are common.

How common is still argued about. In October 2026, Nick Cammarata, a co-author of "Zoom In", published an essay with the interpretability company Goodfire arguing that most neurons in a large open model have one main job once you look carefully. Its numbers are preliminary and the debate is ongoing.

What is the difference between a neuron and a feature?

  1. They are two names for the same thing
  2. A neuron is one coordinate of an activation vector; a feature is a property of the input the model represents, which need not line up with any single neuron
  3. Features exist only in image models, neurons only in LLMs
  4. A feature is a weight; a neuron is a token
A neuron is a slot in the hardware, so to speak. A feature is a piece of meaning. If each feature used exactly one neuron, reading a model would be easy; polysemantic neurons show it usually doesn't.

Features as directions

If features aren't neurons, what are they? The leading answer is the linear representation hypothesis: a feature is a direction in activation space, and how strongly the feature is present is how far the activation points along that direction. An activation vector $h$ is then (approximately) a weighted sum of feature directions:

$$h \approx \sum_i f_i\, d_i$$

Here $d_i$ is the unit-length direction of feature $i$, and $f_i \ge 0$ is how active that feature is on this input (mostly zero). To read feature $i$, take a dot product (P1.1): $r_i = d_i \cdot h$. If the directions were all perpendicular, $r_i$ would recover $f_i$ exactly.

The first hint came from word vectors. Mikolov et al. (2013) found that in word2vec embeddings, $\text{vec}(\text{king}) - \text{vec}(\text{man}) + \text{vec}(\text{woman})$ lands closest to $\text{vec}(\text{queen})$ (P3.4): "male → female" behaves like one direction you can add or subtract. In LLMs, simple linear classifiers can read sentiment, truth-value and even a place's latitude and longitude out of activations (Gurnee & Tegmark, 2023), and Park, Choe & Veitch (2023) gave the hypothesis a formal statement. It is a hypothesis, not a law: Engels et al. (2024) found some features that are genuinely multi-dimensional, such as days of the week and months arranged on circles.

Notice what the hypothesis doesn't say: nothing forces a feature's direction to line up with a neuron. In the residual stream (M1.4) no activation function acts on single coordinates, so nothing in the architecture singles out the neuron axes; directions can point anywhere. (In practice the optimiser and LayerNorm give the axes a slight preference, Elhage et al., 2023, but not enough to make single neurons the unit of meaning.) Inside an MLP, the activation function is applied neuron by neuron, which gives the neuron basis some meaning, and that's where monosemantic neurons are most often found.

Under the linear representation hypothesis, how do you measure how strongly a feature is present in an activation $h$?

  1. Take the dot product of $h$ with the feature's direction
  2. Read the value of the neuron with the same index as the feature
  3. Count how many neurons are non-zero
  4. Take the length of $h$
A feature is a direction, so its strength is the projection of $h$ onto that direction: $d_i \cdot h$. A single neuron only measures one particular direction, an axis, which usually isn't a feature's.

Superposition: more features than dimensions

A model with a 4,096-dimensional residual stream can hold at most 4,096 perfectly perpendicular directions. But the world has far more than 4,096 things worth representing: every famous person, programming language, grammatical role and topic. Elhage et al. (2022, "Toy Models of Superposition") showed in a tiny model how networks escape this limit. Their setup takes $n$ input features, squeezes them into $m < n$ dimensions, and asks the network to get them back out:

$$h = W x, \qquad \hat{x} = \mathrm{ReLU}\big(W^{\top} h + b\big)$$

Here $x$ holds the $n$ feature values, $W$ is an $m \times n$ matrix whose column $i$ is feature $i$'s direction in the small space, $h$ is the $m$-dimensional hidden activation, $b$ is a bias per feature, and the loss is squared error weighted by each feature's importance. The key knob is sparsity: how often each feature is zero.

  • Dense features (all on at once): the model keeps only the $m$ most important features, each in its own perpendicular direction, and ignores the rest. A linear model always does this, the same way PCA (P6.4) keeps only the top components.
  • Sparse features (each rarely on): the model stores more features than dimensions, at angles that overlap a little. Five features in two dimensions arrange themselves as a pentagon.

Superposition works because of the ReLU and bias. When feature A is on, every other feature's reading picks up a little interference from A. A negative bias plus the ReLU cuts small and negative readings to zero, so if features rarely occur together, the errors are rare and small. Explain like I'm 5

A closet has only three hooks, but a child has six outfits. So she hangs two on each hook, turned at different angles, and can still pull any one out on its own.

It works because she only wears one outfit at a time. If she needed several at once, the hangers would tangle. Hooks are the model's dimensions; outfits are features; "one at a time" is sparsity.

Where it breaks: a model has no tidy hooks. Every feature is a direction that overlaps a little with many others, and "pulling one out" is a dot product that always drags a bit of the others along.

In the toy model, what makes it worthwhile to store more features than dimensions?

  1. A larger learning rate
  2. Removing the ReLU
  3. Sparse features plus the ReLU and bias, which filter out the small interference between overlapping directions
  4. Making every feature equally important and always on
With dense features or a purely linear model, the network keeps just the top $m$ features, like PCA. Sparsity means overlapping features rarely fire together, and the nonlinearity cleans up the interference when only one does.

Room in high dimensions

A pentagon in 2-D is cramped: neighbours overlap with cosine 0.31. Real models have thousands of dimensions, and there the geometry is far kinder. Two random directions in $d$ dimensions have a cosine similarity that is typically very close to 0: its spread shrinks like $1/\sqrt{d}$. And the number of directions you can fit with every pair nearly perpendicular (say, all cosines below 0.1) grows exponentially with $d$, a consequence of the Johnson–Lindenstrauss lemma (1984). So a residual stream with a few thousand dimensions has room for vastly more than a few thousand almost-perpendicular feature directions, provided the features are sparse enough that only a few are active on any token.

Worked example

Measure it. Draw pairs of random Gaussian vectors, compute their cosine, and average its absolute value:

import numpy as np
rng = np.random.default_rng(0)
for d in [2, 100, 10_000]:
    a = rng.standard_normal((2000, d))
    b = rng.standard_normal((2000, d))
    cos = (a * b).sum(1) / (np.linalg.norm(a, axis=1) * np.linalg.norm(b, axis=1))
    print(d, np.abs(cos).mean().round(3))
  1. $d = 2$: random directions are random angles in a plane, and the average $|\cos|$ is exactly $2/\pi \approx 0.64$. The code prints about 0.63 to 0.65.
  2. For large $d$, the average $|\cos|$ is close to $\sqrt{2/(\pi d)} \approx 0.80/\sqrt{d}$.
  3. So random directions in 2-D overlap a lot, and superposition there is costly. ✓

Why this matters for LLMs: superposition is the main reason you can't understand an LLM by printing its neurons. Each neuron mixes many features, and each feature is spread over many neurons. To read the model, you need to recover the feature directions themselves. That is what the next two lessons do: probes and patching find directions and components that matter (IN.2), and sparse autoencoders try to pull out all the features at once by learning an overcomplete set of directions, with sparsity built in (IN.3).

Why does superposition get easier as the number of dimensions grows?

  1. More dimensions make features denser
  2. High-dimensional vectors are always exactly perpendicular
  3. The ReLU stops working in high dimensions
  4. Random directions overlap less (typical cosine shrinks like $1/\sqrt{d}$), and exponentially many nearly perpendicular directions fit
Not exactly perpendicular, but nearly: interference falls like $1/\sqrt{d}$ while the number of almost-orthogonal directions grows exponentially. That's plenty of room for sparse features.
Explain it back · in two or three sentences

What is superposition, why does a network use it, and when does it break down?

Model answer: Superposition is storing more features than there are dimensions by giving each feature its own direction, with directions that overlap slightly instead of being perfectly perpendicular. A network does this because there are far more useful features than neurons, and when features are sparse, a ReLU with a negative bias can filter out the small interference when only one is on. It breaks down when several overlapping features are active at once: their interference adds up, giving false readings for features that are off and weak readings for those that are on.
Check yourself

In the toy model of superposition, features are made dense (all on at once) and there are $m = 2$ hidden dimensions. What does the trained model do?

  1. Stores all five features as a pentagon
  2. Stores only the two most important features, in perpendicular directions, and drops the rest
  3. Stores no features at all
  4. Stores all features along one shared direction
With dense features, interference would be constant and costly, so the model keeps the top $m$ by importance in perpendicular directions, like PCA. Superposition only pays off when features are sparse.

Feature directions A and B are 72° apart. Only A is on, with strength 1. Reading B by dot product gives about 0.31. What turns that into the correct 0?

  1. A ReLU after a bias of about −0.35
  2. Normalising $h$ to length 1
  3. Reading the neuron with B's index instead
  4. Adding a second copy of A
$\max(0, 0.31 - 0.35) = 0$. The bias sets a threshold below which interference is ignored, which is exactly the job the ReLU and bias do in the toy model.

Interleaving with M1.4: where would you expect neuron-aligned (monosemantic) features to be most likely, and why?

  1. In the residual stream, because it's the widest vector
  2. In the token embedding table, because it has one row per token
  3. In the softmax output, because probabilities sum to 1
  4. Inside the MLP's hidden layer, because its activation function acts on each neuron separately, which makes the neuron axes special
The residual stream is only ever added to and read by matrix multiplications, so any rotation of it works equally well and its axes have no special meaning by design. An elementwise nonlinearity gives each MLP neuron its own threshold, a reason for features to align with neurons, though superposition still makes many of them polysemantic.

Interleaving with P1.1: you normalise all feature directions to unit length. What does the dot product of two of them equal?

  1. The sum of their lengths
  2. Always 0
  3. The cosine of the angle between them, which is their interference
  4. The number of active features
For unit vectors, $a \cdot b = \cos\theta$. That cosine is exactly how much reading one feature picks up when the other is on.

Key takeaways

  • Interpretability looks inside models for debugging, safety and science. The unit of meaning is a feature, not a neuron.
  • Linear representation hypothesis: features are directions, $h \approx \sum_i f_i d_i$; read one with a dot product. (Some features, like days of the week, are circles instead.)
  • Polysemantic neurons respond to several unrelated things, because features don't have to align with neurons.
  • Superposition (Elhage et al., 2022): with sparse features, a network stores more features than dimensions at slightly overlapping angles, and a ReLU with bias filters the interference.
  • In $d$ dimensions random directions have $|\cos| \approx 0.8/\sqrt{d}$, so high-dimensional models have huge room for nearly perpendicular features.
