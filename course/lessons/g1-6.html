Diffusion transformers & autoregressive images

Lesson 6 of Image generation

The transformer won language, then vision. Image generation followed two ways: replace the diffusion U-Net with a transformer over latent patches, or skip diffusion and generate image tokens the way an LLM generates words. As of 2026, frontier systems use one, the other, or both.

  • Describe MMDiT's joint text–image attention and count tokens and attention cost for a given resolution.
  • Compare raster autoregression, MaskGIT and VAR, and describe the trend toward LLMs that generate images.

From U-Nets to transformers: DiT

By 2022 transformers dominated language and, with the Vision Transformer (V1.1), image recognition, and they scaled predictably with compute. Diffusion models still used convolutional U-Nets. Peebles & Xie (2022, "Scalable Diffusion Models with Transformers") asked whether the U-Net's inductive biases were needed. Their DiT replaced it with a plain transformer working on the latent of Stable Diffusion's VAE:

  1. Patchify: cut the $I \times I \times C$ latent into $p \times p$ patches and linearly embed each as one token, plus positional embeddings. That gives $(I/p)^2$ tokens.
  2. Transformer blocks: standard self-attention and MLP blocks over all patch tokens.
  3. Conditioning with adaLN: the time step $t$ and the class label are embedded and passed through an MLP that outputs, for every block, the scale $\gamma$ and shift $\beta$ of its layer norms. The best variant, adaLN-Zero, also outputs a gate $\alpha$ on each residual branch, initialised to zero, so every block starts as the identity function and training is stable.
  4. Unpatchify: a final linear layer turns each token back into a $p \times p \times C$ patch of predicted noise (and variance).

The key finding was scaling. Sample quality improved steadily with the compute per forward pass (measured in GFLOPs), whether that came from a bigger model or from smaller patches (more tokens). The largest model, DiT-XL/2, reached an FID of 2.27 on class-conditional ImageNet 256×256 with guidance, beating the previous U-Net diffusion models. That predictability, the same property that made LLMs bankable, is why DiT-style backbones took over large image and video generators.

Worked example

A 256×256 image through an $f = 8$, 4-channel VAE, with patch size $p = 2$:

  1. Latent: $256/8 = 32$, so $32 \times 32 \times 4$.
  2. Tokens: $(32/2)^2 = 16^2 = 256$.
  3. Each token flattens a $2 \times 2 \times 4$ patch: 16 numbers, then a linear layer maps it to the model width.

MMDiT: text and image in one attention

DiT conditioned on a class label. For text-to-image you need the prompt. U-Nets read it through cross-attention (G1.4), where image features query the text but the text never updates. Stable Diffusion 3 (Esser et al., 2024) introduced the MMDiT (multimodal DiT) block:

  • Two token streams: text tokens from the text encoders (CLIP and T5) and image patch tokens from the latent.
  • Each stream has its own weights (its own QKV projections, MLPs and norms), because the two modalities are so different.
  • For attention, the two sequences are concatenated, so every image token attends to every text token and vice versa: joint attention, updating both streams in every block.
  • The time step and a pooled text embedding still come in through adaLN.

SD3's paper scaled this up to 8 billion parameters and reported that quality kept improving with model size. FLUX.1 (Black Forest Labs, 2024) uses a related design, mixing joint-attention blocks with single-stream blocks, per its developers. The same transformer-over-patches idea extends to video by cutting space-time patches; OpenAI described Sora (2024) as a diffusion transformer of this kind (VD2).

What is the main difference between MMDiT's joint attention and the cross-attention in Stable Diffusion 1.x?

  1. In joint attention, text and image tokens attend to each other in both directions, and both streams are updated in every block
  2. Joint attention uses no text encoder
  3. Cross-attention is bidirectional, joint attention is not
  4. Joint attention runs only once, at the start
In cross-attention the image queries the text, but text features stay fixed. MMDiT concatenates both sequences, so text representations also adapt to the image as it forms.

Images as tokens, and LLMs that draw

The other route skips diffusion. Turn an image into a sequence of discrete tokens with a VQ-style tokenizer (G1.1), then train a transformer to predict them one at a time, exactly like next-token prediction in an LLM (M2.2).

  • DALL·E (Ramesh et al., 2021): a discrete VAE turns a 256×256 image into a 32×32 grid of tokens from a vocabulary of 8,192. A 12-billion-parameter transformer reads up to 256 text tokens, then generates the 1,024 image tokens in raster order. Candidates were re-ranked with CLIP.
  • Parti (Yu et al., 2022): a 20-billion-parameter encoder–decoder transformer over ViT-VQGAN tokens, showing autoregressive models also improve with scale.

The drawback is speed: one forward pass per token, and raster order is an odd way to paint. Two ideas changed the order:

  • MaskGIT (Chang et al., 2022): a bidirectional transformer trained to fill in masked tokens. At generation, start with every token masked, predict all of them at once, keep the most confident, re-mask the rest and repeat. Their 256×256 images (16×16 = 256 tokens) needed about 8 rounds instead of 256 steps. Muse (Chang et al., 2023) used this for text-to-image.
  • VAR (Tian et al., 2024, "Visual Autoregressive Modeling"): autoregress over scales instead of positions. Predict a 1×1 token map, then 2×2, then 4×4 and so on, each whole map in one step, conditioned on all coarser ones. The authors reported better quality than DiT models of similar size on ImageNet 256×256, with faster sampling; the paper won a NeurIPS 2024 best paper award.

LLMs that draw

If images are tokens, an LLM can generate them too. Several 2024–26 systems are trained on interleaved text and image tokens so one model reads and writes both:

  • Chameleon (Meta, 2024): "early fusion", with text and VQ image tokens in one vocabulary and one next-token objective.
  • Transfusion (Zhou et al., 2024): one transformer trained with next-token loss on text and a diffusion loss on continuous image patches.
  • Janus and Janus-Pro (DeepSeek, 2024–25): separate visual encoders for understanding and for generation inside one autoregressive model.
  • Closed models: in March 2025 OpenAI launched image generation built into GPT-4o and described it as autoregressive and native to the model, and Google added native image output to Gemini models during 2025. These labs published little about architecture; some systems appear to pair an autoregressive backbone with a diffusion-style decoder, so treat specific claims cautiously.

Why bother, when diffusion works so well? A model that shares weights with an LLM brings its world knowledge and instruction following to images. That shows up as better rendering of text inside images, following long and specific prompts, and multi-turn editing in conversation ("now make the cat wear a hat"). MM2 covers these natively multimodal models in depth.

Explain like I'm 5

Think of a picture cut into a jigsaw of little square pieces.

A diffusion transformer gets all the pieces covered in smudges and cleans every piece a little at a time, while each piece "talks" to all the others about what the whole picture should be.

An autoregressive model fills the jigsaw from an empty board: one piece at a time, top-left to bottom-right (DALL·E), or a few sure pieces at a time anywhere on the board (MaskGIT), or first a blurry tiny version, then a sharper one, then a sharper one (VAR).

Where it breaks: the real pieces aren't little pictures; they're codes or number patches that only the model's decoder knows how to turn back into pixels.

Why this matters for LLMs: the line between "LLM" and "image generator" is blurring. The same transformer blocks, scaling laws and serving tricks (KV caching for autoregressive image tokens, M1.5) now apply to pictures, and the multimodal assistants you use may produce images with the same model that writes their replies.

What does Transfusion combine in one transformer?

  1. A GAN generator and discriminator
  2. A next-token loss on text and a diffusion loss on continuous image patches
  3. Two separate diffusion models
  4. A U-Net and a VQ codebook
It shows that one model can be autoregressive for text and diffusion-based for images at the same time, one of several recipes for natively multimodal generation.
Explain it back · in two or three sentences

Contrast how a diffusion transformer and an autoregressive image model produce an image from a prompt.

Model answer: A diffusion transformer patchifies a noisy latent into tokens, runs transformer blocks conditioned on the time step and text (via adaLN and joint attention), and predicts the noise for all patches at once, repeating over many denoising steps before a VAE decodes the result. An autoregressive model represents the image as discrete tokens and predicts them sequentially after the text, one at a time (DALL·E), in confident parallel batches (MaskGIT) or scale by scale (VAR), then a tokenizer decoder turns the tokens into pixels.
Check yourself

What did Peebles & Xie find about scaling DiT?

  1. Quality stopped improving beyond small models
  2. Quality improved steadily with compute per forward pass (GFLOPs), from bigger models or smaller patches
  3. Larger patches always gave better images
  4. U-Nets scaled better than transformers
FID fell as GFLOPs rose, across model sizes and patch sizes, and DiT-XL/2 reached 2.27 on ImageNet 256×256.

From M1.1 and V1.1: you halve a DiT's patch size from 4 to 2 at fixed resolution. What happens to the self-attention cost per layer?

  1. It halves
  2. It stays the same
  3. It doubles
  4. About 16× more, because there are 4× as many tokens and attention compares every pair
Halving $p$ doubles the tokens per side, so 4× tokens and $4^2 = 16×$ token pairs. That's why smaller patches give better but much costlier models.

VAR's "next-scale prediction" means…

  1. Generating whole token maps from coarse (1×1) to fine, each conditioned on the coarser ones
  2. Predicting the next pixel in raster order
  3. Upscaling a finished image with a separate model
  4. Predicting the noise scale at each diffusion step
Each autoregressive step outputs an entire, larger token map, so a full image takes only as many steps as there are scales.

In the time step's journey into a DiT block, what does adaLN produce?

  1. Extra tokens appended to the sequence
  2. A new attention mask
  3. Per-block scale and shift for the layer norms (and, in adaLN-Zero, a residual gate)
  4. The patch size
An MLP maps the time and condition embeddings to $\gamma$, $\beta$ (and $\alpha$), which modulate every block's normalized activations.

Key takeaways

  • DiT: patchify the latent ($(I/p)^2$ tokens), transformer blocks with adaLN-Zero conditioning, unpatchify to predicted noise; quality scales with GFLOPs.
  • MMDiT (SD3): separate text and image weights, one joint attention over both.
  • Autoregressive image models predict discrete tokens: raster (DALL·E, Parti), parallel unmasking (MaskGIT), or coarse-to-fine scales (VAR).
  • Natively multimodal LLMs now generate images too; closed labs disclose little, and hybrids with diffusion decoders are common.
