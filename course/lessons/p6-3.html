RNNs & LSTMs (and why Transformers won)

Lesson 3 of Classic deep-learning architectures

Before Transformers, language models read text the way you do: one word at a time, carrying a running memory. That memory is the hidden state of a recurrent neural network. This lesson shows why plain RNNs forget, how the LSTM's gated "conveyor belt" fixed it, why attention still won, and why recurrence is making a comeback.

By the end you can

  • Run an RNN step by hand, and explain unrolling and backpropagation through time.
  • Explain vanishing and exploding gradients with numbers, and what gradient clipping does and doesn't fix.
  • Describe the LSTM's gates and cell state, and give three reasons Transformers replaced RNNs.
Builds on: MLPs: an RNN step is one small neural-network layer, applied again and again. Helpful but optional: Backpropagation, since backprop through time is the same chain rule on a longer chain.

A gradient is multiplied by 0.9 at each of 50 time steps on its way back. What's left?

  1. About 0.45
  2. About 0.005
  3. About 0.1
  4. Exactly 0
$0.9^{50} \approx 0.0052$. Small factors compound fast. That's the vanishing gradient problem, and it's why plain RNNs struggle to learn long-range dependencies.

Why can a Transformer be trained much faster on GPUs than an RNN of similar size?

  1. It has fewer parameters
  2. It doesn't need backpropagation
  3. It uses smaller vectors
  4. It processes all positions of a training sequence in parallel, while an RNN must go step by step
An RNN can't compute step $t$ until step $t-1$ is done. Attention computes every position at once with big matrix multiplies, which is exactly what GPUs are good at.

A network with a memory

An MLP (P3.1) takes a fixed-size input. Sentences aren't fixed-size, and their meaning depends on order. The recurrent answer, developed in the 1980s (Jordan, 1986; Elman, 1990, "Finding Structure in Time"), is to read the sequence one element at a time and keep a running summary, the hidden state $h_t$:

$$h_t = \tanh\!\big(W h_{t-1} + U x_t + b\big)$$

$x_t$ is the input at step $t$ (say, a token's embedding), $h_{t-1}$ is the previous hidden state (a vector of, say, 512 numbers; $h_0$ is usually zeros), $W$ and $U$ are learned weight matrices, $b$ is a bias, and $\tanh$ squashes every entry into $(-1, 1)$. The crucial detail: the same $W$, $U$ and $b$ are used at every step. To predict the next token, a language model adds an output layer, $\mathrm{softmax}(V h_t)$ (P3.2). Mikolov et al. (2010) showed such RNN language models beat the n-gram models of the day.

Draw one copy of the network per time step and you get the unrolled RNN: a very deep feed-forward network whose depth equals the sequence length, with all layers sharing one set of weights.

Worked example

A one-number RNN with $W = 0.5$, $U = 1$, $b = 0$, reading the inputs $x = (1, 0, 0)$: a signal, then silence.

  1. $h_1 = \tanh(0.5 \cdot 0 + 1) = \tanh(1) = 0.762$
  2. $h_2 = \tanh(0.5 \times 0.762) = \tanh(0.381) = 0.363$
  3. $h_3 = \tanh(0.5 \times 0.363) = \tanh(0.182) = 0.180$. The memory of that first input more than halves at every step.

Backprop through time: vanishing and exploding gradients

To train an RNN, unroll it and run ordinary backpropagation through the whole chain. This is backpropagation through time (BPTT; Rumelhart, Hinton & Williams, 1986; Werbos, 1990). The gradient that tells step 1 how it affected the loss at step $T$ passes back through every step in between:

$$\frac{\partial h_T}{\partial h_1} = \prod_{t=2}^{T} \frac{\partial h_t}{\partial h_{t-1}}, \qquad \frac{\partial h_t}{\partial h_{t-1}} = \mathrm{diag}\!\big(\tanh'(\cdot)\big)\, W$$

The product runs over the $T-1$ steps, and each factor is the same $W$, scaled by tanh's slope (at most 1). For a one-number RNN each factor is just $W \cdot \tanh'$. Multiply the same number many times and it either shrinks or blows up:

  • $0.9^{50} \approx 0.005$: the gradient from 50 steps back vanishes. The network can't learn that a word 50 tokens ago mattered.
  • $1.1^{50} \approx 117$: it explodes, and one bad update can wreck training.

For matrices the same thing happens along directions, governed by the size of $W$'s largest eigenvalues. Sepp Hochreiter analysed this in his 1991 diploma thesis, and Bengio, Simard & Frasconi (1994, "Learning Long-Term Dependencies with Gradient Descent is Difficult") showed it is a basic obstacle for gradient-trained RNNs.

Explain like I'm 5

Remember the telephone game? The first child sees a picture of an apple and whispers it to the next child, who whispers to the next, and so on.

Each child passes on a slightly fuzzier version. By the end of a long line, the apple is faint and blurry, or gone. A plain RNN is that line of children: each step passes the memory on through the same squashing, and old things fade.

Where it breaks: in the game, mistakes are random. In an RNN the fading follows a rule (multiplying by the same weights each step), which is exactly why a better design, the LSTM, can fix it.

Gradient clipping handles explosions (Pascanu, Mikolov & Bengio, 2013): if the gradient's norm $\lVert g \rVert$ exceeds a threshold $c$, rescale it to length $c$:

$$g \leftarrow g \cdot \frac{c}{\lVert g \rVert} \quad \text{if } \lVert g \rVert > c$$

The direction is kept and only the step size is capped. For example, $g = (30, 40)$ has norm 50; clipped to $c = 5$ it becomes $(3, 4)$. LLM pretraining still clips the global gradient norm, typically at 1.0 (M2.3). But clipping can't enlarge a vanishing gradient: there's no signal left to rescale. That needed a new architecture.

LSTM: a conveyor belt with gates

Hochreiter & Schmidhuber's long short-term memory (1997) adds a second state, the cell state $c_t$, which is updated by addition instead of being squashed through a matrix every step. Small learned gates, each a sigmoid layer $\sigma(\cdot)$ outputting numbers between 0 and 1, decide what to erase, what to write and what to reveal. The modern version, with the forget gate added by Gers, Schmidhuber & Cummins (2000), is:

$$\begin{aligned} f_t &= \sigma(W_f [h_{t-1}, x_t] + b_f) && \text{forget gate}\\ i_t &= \sigma(W_i [h_{t-1}, x_t] + b_i) && \text{input gate}\\ \tilde{c}_t &= \tanh(W_c [h_{t-1}, x_t] + b_c) && \text{candidate}\\ c_t &= f_t \odot c_{t-1} + i_t \odot \tilde{c}_t && \text{cell state}\\ o_t &= \sigma(W_o [h_{t-1}, x_t] + b_o) && \text{output gate}\\ h_t &= o_t \odot \tanh(c_t) \end{aligned}$$

$[h_{t-1}, x_t]$ means the two vectors stacked into one, and $\odot$ is element-wise multiplication. The forget gate says how much of each cell entry to keep, the input gate how much of the new candidate to write, and the output gate how much of the cell to show as $h_t$.

Look at the cell update. Along the cell state, the derivative from one step to the next is just $f_t$ (plus smaller indirect terms through $h$). If the network learns $f_t \approx 1$ for something worth remembering, the signal and its gradient pass through almost untouched: $0.99^{50} \approx 0.61$, versus $0.9^{50} \approx 0.005$. Hochreiter and Schmidhuber called this the "constant error carousel". It's the same trick as the ResNet skip connection (P6.2): an additive path for gradients. Highway networks, a direct precursor of ResNets, borrowed the LSTM's gates. A common practice is to initialise the forget-gate bias to 1, so the cell starts out remembering (recommended by Jozefowicz, Zaremba & Sutskever, 2015).

The GRU (Cho et al., 2014) is a lighter variant with two gates (update and reset) and no separate cell state. It has three weight blocks where an LSTM has four, and often performs about as well. That four-block structure makes an LSTM roughly 4× the parameters of a plain RNN of the same size: with input 10 and hidden 20, $4 \times 620 = 2{,}480$ (PyTorch reports 2,560, because it keeps two bias vectors per gate).

Which part of the LSTM lets gradients survive over many steps?

  1. The tanh on the candidate $\tilde{c}_t$
  2. The additive cell-state update, whose step-to-step derivative is the forget gate $f_t$, which can stay close to 1
  3. The output gate, which multiplies gradients by 2
  4. Having more parameters than a plain RNN
$c_t = f_t \odot c_{t-1} + \ldots$ gives $\partial c_t / \partial c_{t-1} = f_t$. With $f_t \approx 1$ there's nothing to shrink the gradient, unlike $\tanh'(\cdot)W$ in a plain RNN.

Seq2seq, attention, and why Transformers won

In 2014, LSTMs took over machine translation. Sutskever, Vinyals & Le ("Sequence to Sequence Learning with Neural Networks") used one deep LSTM, the encoder, to read an English sentence into its final hidden state, and a second LSTM, the decoder, to generate the French translation from that vector, one word at a time. An ensemble of five of their 4-layer LSTMs reached a BLEU score of 34.8 (a single one scored about 30.6) on the WMT'14 English→French task; oddly, simply reversing the source sentence helped, because it put the first source words close to the first target words. Cho et al. (2014) proposed the same encoder–decoder idea with GRUs.

The weak point was obvious: the whole sentence had to squeeze through one fixed-size vector. Bahdanau, Cho & Bengio (2014, "Neural Machine Translation by Jointly Learning to Align and Translate") let the decoder look back at all the encoder's hidden states at every step and take a weighted average of them, with weights computed from how well each state matched what the decoder needed. That is attention, born as an add-on to RNNs. Google's production translation system (GNMT; Wu et al., 2016) was an 8-layer LSTM encoder–decoder with attention.

A year later came the obvious question: if attention does the useful work, do we still need the recurrence? (Lesson M1.1 picks up the story.)

Why Transformers won, and the recurrent comeback

"Attention Is All You Need" (Vaswani et al., 2017) dropped recurrence entirely. Three advantages decided it:

  1. Parallel training. An RNN must compute $h_1$, then $h_2$, then $h_3$: $T$ sequential steps per sequence. Self-attention handles all $T$ positions of a training sequence at once with large matrix multiplies, which keeps a GPU busy.
  2. Direct long-range paths. In an RNN, information from token 1 reaches token 500 through 499 steps of squashing. In attention, any token can read any earlier token in one step: the maximum path length is $O(1)$ instead of $O(T)$.
  3. Scale. Because they train efficiently, Transformers could be made much bigger and fed much more data, and they kept improving (scaling laws).

The price: attention compares every pair of tokens, so compute grows as $T^2$, and generation must keep a KV cache that grows with every token (M1.5). An RNN carries a fixed-size state, however long the text.

That trade-off brought recurrence back. The trick is to make the recurrence linear, with no tanh between steps, e.g. $h_t = A_t h_{t-1} + B_t x_t$. Linear recurrences can be unrolled algebraically and computed in parallel during training (as a convolution or a parallel scan), yet still run step by step with a constant-size state at inference. Structured state-space models (S4; Gu, Goel & Ré, 2021), Mamba (Gu & Dao, 2023), RWKV (Peng et al., 2023), linear attention ("Transformers are RNNs", Katharopoulos et al., 2020) and xLSTM (Beck et al., 2024) all follow this line. As of 2026 several production LLMs are hybrids that interleave a few attention layers with many such recurrent layers. You'll meet them in State-space models & Mamba and Hybrid & linear-attention models.

Why this matters for LLMs: the vocabulary of today's LLMs comes from the RNN era: next-token language modelling, encoder–decoder, attention, gradient clipping, gating. Gates in particular live on: the SwiGLU MLP in most open LLMs (P3.1) multiplies one branch by a learned gate, LSTM-style, and Mamba's selective state update is a gated linear recurrence. Whenever you see a long-context model advertise "constant memory per token", you're looking at the RNN's fixed-size state, made trainable at scale.

What makes modern linear recurrences (state-space models such as Mamba) trainable in parallel, unlike a classic RNN?

  1. They use attention internally at every step
  2. They have no hidden state
  3. The step-to-step update has no nonlinearity, so the whole sequence can be computed with a parallel scan or convolution
  4. They only work on short sequences
Without tanh between steps, $h_T$ is an explicit sum of terms that can be computed for all positions at once in training, while inference keeps the RNN's constant-size state.
Explain it back · in two or three sentences

Why do plain RNNs struggle with long-range dependencies, how does an LSTM help, and why did Transformers still win?

Model answer: Backprop through time multiplies one Jacobian per step, roughly $\tanh' \cdot W$, so gradients from far back shrink (or blow up) exponentially, e.g. $0.9^{50} \approx 0.005$. An LSTM carries a cell state updated by addition, $c_t = f_t c_{t-1} + i_t \tilde{c}_t$, so with forget gates near 1 the signal and its gradient pass through almost unchanged. Transformers still won because attention trains on all positions in parallel and connects any two tokens in one step, which let them scale far further; the cost is quadratic attention and a growing KV cache.
Check yourself

In $h_t = \tanh(W h_{t-1} + U x_t + b)$, what does $W$ do?

  1. Maps the input token into the hidden space
  2. Turns the hidden state into next-token probabilities
  3. Mixes the previous hidden state into the new one: it's the recurrent weight matrix
  4. Normalizes the hidden state
$U$ handles the input, $W$ the memory. The gradient's repeated product of $W$ (times tanh slopes) is what vanishes or explodes.

An LSTM's forget gate outputs 0.95 on a cell entry for 40 steps in a row. Roughly how much of that entry's original value (and gradient) survives along the cell state?

  1. About 13%
  2. About 95%
  3. About 0.01%
  4. Exactly 0
$0.95^{40} \approx 0.13$. Gates near 1 keep memories for a long time; 0.99 would keep about 67% after 40 steps.

Interleaving with P6.2: which ResNet idea is closest to the LSTM's cell state?

  1. Pooling between stages
  2. BatchNorm after each conv
  3. The bottleneck $1 \times 1$ convs
  4. The skip connection: an additive path that carries the signal and its gradient through many steps almost unchanged
$c_t = f_t c_{t-1} + i_t \tilde{c}_t$ and $y = x + F(x)$ are both "keep what you had, add a correction". Highway networks made the link explicit by putting LSTM-style gates on a skip connection.

During generation, what is one real advantage an RNN (or SSM) still has over a Transformer?

  1. It can look at every earlier token directly
  2. Its memory per sequence stays a fixed size, while a Transformer's KV cache grows with every token
  3. It trains faster on GPUs
  4. It never needs a softmax
The RNN's whole past is squeezed into $h_t$. That's a weakness for exact recall but a strength for memory and speed on very long sequences, which is why hybrids are attractive.

Key takeaways

  • An RNN updates a hidden state with shared weights: $h_t = \tanh(W h_{t-1} + U x_t + b)$. Unrolled, it's a deep net as long as the sequence.
  • Backprop through time multiplies one factor per step, so gradients vanish ($0.9^{50} \approx 0.005$) or explode ($1.1^{50} \approx 117$). Clipping tames explosions only.
  • The LSTM adds a cell state updated by addition and controlled by forget, input and output gates; the GRU is a lighter two-gate cousin.
  • Seq2seq LSTMs plus attention (2014) led to the Transformer (2017), which won through parallel training, $O(1)$ paths between tokens, and scale.
  • Linear recurrences (S4, Mamba, RWKV, xLSTM) bring back the fixed-size state with parallel training; hybrids mix them with attention.
