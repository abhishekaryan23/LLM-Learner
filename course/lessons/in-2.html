Probing & circuits

Lesson 2 of Interpretability

Knowing that features are directions is one thing; finding the ones that matter is another. This lesson is the interpretability toolkit: probes ask whether information is there, patching asks whether it is used, lenses and steering vectors read and write the residual stream, and circuits trace how components pass information to each other.

By the end you can

  • Train a linear probe in your head, and explain why "decodable" doesn't mean "used".
  • Describe activation patching (clean run, corrupted run, patch, measure) and compute the fraction of an answer it recovers.
  • Explain the logit lens, steering vectors and two classic circuits: induction heads and the indirect-object circuit.
Prerequisites: IN.1 Features & superposition: features as directions, read with a dot product. Helpful but optional: M1.1 Attention and M1.4 The decoder-only transformer (the residual stream and the unembedding).
Warm-up · guess before you learn

Guess first. A wrong guess now makes the right answer stick.

A simple classifier can predict, from a layer's activations, whether a sentence's subject is plural. What does that prove?

  1. The model uses plurality to choose its next token
  2. The model was trained on grammar labels
  3. That layer computes plurality and nothing else
  4. Only that the information can be read out of that layer; not that the model relies on it
Decodable is not the same as used. Showing that the model uses it takes an intervention: change the representation and see whether the output changes.

You add a fixed vector to a chatbot's activations at one layer on every token, and its replies become noticeably more upbeat. What is this called?

  1. Activation steering (a steering vector)
  2. Fine-tuning
  3. Prompt engineering
  4. Quantization
No weights change and the prompt is the same: you nudge the residual stream along a direction. If features are directions (IN.1), adding a direction should turn a feature up, and often it does.

Probes: is the information there?

The oldest tool is the simplest. Alain & Bengio (2016, "Understanding intermediate layers using linear classifier probes") froze a trained network and fitted a small linear classifier on each layer's activations to predict a property. If a linear probe succeeds, the property is linearly readable at that layer. For a yes/no property, the probe is logistic regression on the activation vector $h$:

$$\hat{p} = \sigma\big(w \cdot h + b\big)$$

Here $w$ is a learned weight vector (a direction in activation space, exactly the kind of direction IN.1 talked about), $b$ a bias, and $\sigma$ the sigmoid that squashes the score into a probability. The LLM itself stays frozen; only $w$ and $b$ are trained, on a labelled dataset of activations.

Probes found a lot. BERT's layers encode part-of-speech, then syntax, then meaning roughly in the order of a classical NLP pipeline (Tenney et al., 2019), and a "structural probe" recovers parse trees as distances between word vectors (Hewitt & Manning, 2019). A GPT trained only on Othello move sequences turned out to track the board state (Li et al., 2023); with the right framing ("my piece vs their piece" instead of "black vs white") the board was even linearly readable (Nanda et al., 2023). Llama-2 activations linearly encode a place's latitude and longitude and an event's date (Gurnee & Tegmark, 2023).

But probes have a well-known catch: decodable ≠ used.

  • The probe might do the work. A powerful enough probe can learn a task from almost any representation. Hewitt & Liang (2019) proposed control tasks: give the same inputs random labels and see how well the probe does. A good probe has high selectivity (real-task accuracy minus control-task accuracy), and simple linear probes tend to be more selective than MLP probes.
  • Correlation, not use. Information can sit in a layer as a by-product that the model never reads. Removing the probed information and checking whether behaviour changes (Elazar et al., 2021, "amnesic probing") is one way to test use; causal interventions, next, are the general answer.

Worked example

A linear probe predicts "is this statement true?" from layer-16 activations with 91% accuracy. The same probe architecture trained on the same inputs with shuffled labels reaches 58% (chance is 50%, a little memorisation adds the rest).

  1. Selectivity $= 91\% - 58\% = 33$ percentage points.
  2. The truth information is clearly there, beyond what the probe can memorise. ✓
  3. It still doesn't show that the model uses this direction when it answers.

What does a control task (Hewitt & Liang, 2019) measure?

  1. How fast the LLM runs with a probe attached
  2. Whether the model uses the probed property
  3. How much of the probe's accuracy comes from the probe itself learning the labels, by training it on random labels
  4. The accuracy of the LLM on its original task
If a probe scores nearly as well on shuffled labels, its success says little about the representation. Selectivity (real minus control accuracy) separates "the information is there" from "the probe is clever". Whether the model uses it needs an intervention.

Activation patching: is it used?

To show that a component matters, change it and watch the output. Vig et al. (2020) brought this causal mediation idea to transformers, and Meng et al. (2022, "Locating and Editing Factual Associations in GPT", the ROME paper) made it famous as causal tracing. Today the general recipe is called activation patching:

  1. Clean run: a prompt the model gets right, e.g. "Eiffel Tower is in" → Paris. Save every internal activation.
  2. Corrupted run: a prompt that changes the answer, e.g. "Big Ben is in" → London. (ROME instead added noise to the subject's embeddings.)
  3. Patched run: run the corrupted prompt again, but overwrite one component, such as one layer's residual stream at one position or one attention head's output, with its value from the clean run.
  4. Measure: how much of the clean answer comes back.

A common score is the fraction recovered, measured on probabilities or, often better, on the logit difference between the right and wrong answers:

$$\text{recovered} = \frac{m_{\text{patched}} - m_{\text{corrupt}}}{m_{\text{clean}} - m_{\text{corrupt}}}$$

Here $m$ is the chosen metric (e.g. logit of "Paris" minus logit of "London") in each run. 0 means the patch did nothing; 1 means it fully restored the clean behaviour. In GPT-2 XL, Meng et al. found that MLPs in the middle layers, at the last token of the subject, were decisive for recalling facts, and they used that location to edit facts (ROME).

Patching has its own pitfalls. Results depend on how you corrupt and which metric you use (Zhang & Nanda, 2023; Heimersheim & Nanda, 2024). Components can back each other up, so knocking out one may show no effect. And "where patching localises a fact" turned out not to predict the best layer to edit it (Hase et al., 2023). Patching every component of a big model is also expensive, so attribution patching approximates all patches at once with gradients (Nanda, 2023; Kramár et al., 2024).

Worked example

Logit difference (Paris − London): clean $4.0$, corrupted $-3.0$, after patching one head $2.6$.

  1. Gap the patch could close: $4.0 - (-3.0) = 7.0$.
  2. Gap it did close: $2.6 - (-3.0) = 5.6$.
  3. Recovered: $5.6 / 7.0 = 0.8$. That head carries most of the effect. ✓

In activation patching, what goes into the patched run?

  1. The clean prompt, with one activation taken from the corrupted run
  2. The corrupted prompt, with one activation replaced by its value from the clean run
  3. A random prompt with all activations zeroed
  4. The clean prompt with retrained weights
Start from the run that gets it "wrong" and restore one piece of the "right" run. If the answer comes back, that piece carries the information that made the difference. (Patching the other way round, clean prompt with one corrupted piece, is also used; it tests whether a component is necessary rather than sufficient.)

Reading and writing the residual stream

Every layer of a decoder-only transformer adds to one running vector, the residual stream, and at the end the model multiplies it by the unembedding matrix to get logits (M1.4). In 2020 a blogger writing as nostalgebraist asked: what if you apply that final step early? Take the residual stream after layer $\ell$, apply the final norm and the unembedding, and read off a next-token distribution. This logit lens showed GPT-2 forming its guess gradually, often getting the right token several layers before the end.

The logit lens works poorly on some models, because early layers don't speak the final layer's "language" yet. Belrose et al. (2023, "Eliciting Latent Predictions from Transformers with the Tuned Lens") train a small affine translator per layer, a matrix and bias that maps that layer's residual stream to something the unembedding can read. The tuned lens gives more reliable layer-by-layer predictions, at the price of training one small map per layer.

Probes and lenses read. You can also write. If a concept is a direction, adding that direction should turn the concept up:

  • Activation addition (Turner et al., 2023): run the prompts "Love" and "Hate", take the difference of their activations at one layer, and add a multiple of it while the model writes. GPT-2 XL's text turned noticeably more loving, with no training at all.
  • Representation engineering (Zou et al., 2023): collect activations for contrasting prompts (honest vs dishonest, harmless vs harmful), find the main direction that separates them, then use it both to read the concept and to steer it.
  • Averaging many contrast pairs gives sturdier vectors (Rimsky et al., 2024, contrastive activation addition), and refusal in many chat models turned out to be mediated largely by a single direction: remove it and the model stops refusing (Arditi et al., 2024).

Steering is powerful evidence for the linear representation hypothesis, and a practical tool for studying behaviours like sycophancy. It is also blunt: push too hard and fluency drops, and a vector found on one kind of prompt may not transfer to others.

What does the logit lens do?

  1. Applies the model's final norm and unembedding to an intermediate layer's residual stream, to see what it would predict at that point
  2. Trains a new model to imitate each layer
  3. Adds a steering vector to the logits
  4. Measures attention patterns between tokens
It reuses the model's own read-out on an early residual stream. The tuned lens improves it by first passing each layer through a small learned affine map.

Circuits: how the pieces connect

A circuit is a set of features and the weights connecting them that together compute something. Olah et al. (2020, "Zoom In: An Introduction to Circuits") argued that you can understand networks this way, one small subgraph at a time. In an image model they traced curve detectors built from earlier edge detectors, and a car detector assembled from window detectors (expected at the top), car-body detectors (middle) and wheel detectors (bottom).

Two circuits in language models became textbook examples:

  • Induction heads (Elhage et al., 2021; Olsson et al., 2022, "In-context Learning and Induction Heads"). Given … Harry Potter … Harry, predict Potter: the pattern [A][B] … [A] → [B]. It takes two attention heads (M1.1) in different layers. A previous-token head writes "the token before me was A" into each position. The induction head then looks for a position whose previous token matches the current token, and copies what came next. Induction heads appear suddenly during training, at the same point as a jump in in-context learning that shows as a bump in the loss curve; Olsson et al. gave causal evidence in small attention-only models and correlational evidence in larger ones.
  • Indirect object identification (Wang et al., 2022, "Interpretability in the Wild"). In "When Mary and John went to the store, John gave a drink to", GPT-2 small predicts Mary. Using patching, the authors mapped a circuit of about two dozen attention heads in seven roles: heads that notice the name John is repeated, heads that use this to suppress it, and name mover heads that copy the remaining name, Mary, to the output.

Doing this by hand takes researcher-months per behaviour. Automated circuit discovery prunes the model's computational graph down to the edges a task needs (ACDC; Conmy et al., 2023), and attribution patching makes that faster. Since 2025 the frontier has moved to circuits built from features rather than neurons or heads, using sparse dictionaries, which is the subject of IN.3.

Explain like I'm 5

A young mechanic wants to know why the robot's bulb lights up when you press its button. She opens the back panel: hundreds of wires.

She shines her flashlight (a probe: "is there a signal here?"), then unplugs one wire at a time and presses the button again (patching: "does the bulb still light?"). The one wire that matters glows from the button to the bulb. That path is a circuit.

Where it breaks: a model's "wires" aren't neatly separate. Many signals share each wire (superposition), several paths can do the same job as backups, and the map you draw is a simplification that explains most, not all, of the behaviour.

Why this matters in practice: these tools are used beyond research papers. Probes on activations are a cheap way to flag things like harmful requests or likely errors. Patching and steering help debug why a model answers the way it does, and steering vectors offer lightweight behaviour control without retraining. And when you read a claim like "the model plans ahead", these are the experiments behind it.

How does an induction head complete [A][B] … [A] → [B]?

  1. It memorises every bigram in the training set
  2. It attends to the very first token of the context
  3. It uses a single MLP neuron that stores B
  4. A previous-token head marks each position with the token before it; the induction head attends to the position after the earlier A and copies B
Two heads compose across layers: one writes "my previous token was A" into position B, and the induction head, sitting at the second A, searches for that mark and copies B forward. It works for token pairs it has never seen, which is why it supports in-context learning.
Explain it back · in two or three sentences

Why isn't a successful probe enough, and how does activation patching fix that?

Model answer: A probe shows that information can be decoded from a layer, but the model might never use it, and a strong probe can partly learn the task itself. Activation patching intervenes instead: run a corrupted prompt, restore one component's activation from a clean run, and measure how much of the clean answer returns. If restoring it brings the answer back, that component causally carries the information.
Check yourself

Clean logit difference 6.0, corrupted 0.0, patched 1.5. What fraction is recovered, and what does it suggest?

  1. 0.75; the component carries most of the effect
  2. 1.5; the patch over-restored it
  3. 0.25; the component carries part of the effect, and other components carry the rest
  4. 0; the component is irrelevant
$(1.5 - 0)/(6.0 - 0) = 0.25$. A partial recovery is common: information is often spread across several components.

Interleaving with IN.1: why does adding a "Love − Hate" difference vector to the activations change the text's sentiment?

  1. If sentiment is represented as a direction, adding that direction increases the feature's strength in every later read-out
  2. It retrains the model's weights toward positive text
  3. It changes the prompt's tokens
  4. It makes the logits uniform
Under the linear representation hypothesis, $h \approx \sum_i f_i d_i$. Adding $\alpha d_{\text{sentiment}}$ raises that feature's coefficient, and any later layer that reads it with a dot product sees "more love".

Interleaving with M1.4: the logit lens can be applied after any layer without training. Which architectural fact makes that possible?

  1. All layers share the same weights
  2. Every layer adds into one residual stream of the same width, which the final norm and unembedding already know how to read
  3. The KV cache stores every layer's logits
  4. Attention is causal
Because each layer only adds to the residual stream, intermediate states live in the same space as the final one, so the unembedding can be applied early. It isn't perfectly calibrated there, which is what the tuned lens fixes.

In the indirect-object circuit, what do the "name mover" heads do?

  1. Detect that a sentence contains two names
  2. Move the subject to the start of the sentence
  3. Suppress every name in the context
  4. Attend to the name that hasn't been repeated and copy it to the output
Earlier heads flag the repeated name (John) and inhibit attention to it; name movers then attend to the remaining name (Mary) and raise its logit.

Key takeaways

  • Linear probes (Alain & Bengio, 2016) test what is decodable; use control tasks for selectivity, and remember decodable ≠ used.
  • Activation patching: clean run, corrupted run, restore one component, measure recovery. Causal tracing (Meng et al., 2022) located facts at mid-layer MLPs on the last subject token.
  • The logit lens reads early residual streams with the unembedding; the tuned lens adds a learned affine map per layer.
  • Steering vectors (Turner et al., 2023; Zou et al., 2023) write a concept direction into the residual stream at inference time.
  • Circuits: induction heads (previous-token head + induction head) and GPT-2's indirect-object circuit (name movers and friends).
