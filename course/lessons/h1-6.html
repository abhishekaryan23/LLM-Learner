Warm-up · guess before you learn

Take your best guess. Being wrong now helps the right answer stick later.

A spam filter labels emails "spam" or "not spam". An image generator draws new pictures. Which pair of words describes them?

  1. Supervised and unsupervised
  2. Discriminative and generative
  3. Small and large
  4. Symbolic and neural
A discriminative model tells things apart (assigns labels). A generative model produces new data. You'll see why an LLM counts as generative.

An LLM is pretrained by predicting the next word of web text. Where do the "correct answers" for that training come from?

  1. Thousands of human labellers
  2. A reward from a game score
  3. The text itself: the next word is the answer
  4. A smaller model that labels the data
This is self-supervised learning: the data supplies its own targets, which is why it scales to trillions of words.

Two questions: what does it output, and how does it learn?

Back in 1958 there was one kind of model: a perceptron that sorted inputs into two classes. Today there are dozens of families, and new names appear every month. Two questions sort most of them.

1. What does it output?

  • A discriminative model maps an input to a label or a number: "cat or dog?", "spam?", "what's the price?". It learns the boundary between classes, like the perceptron's line. Image classifiers and speech-to-text systems are examples.
  • A generative model learns what the data itself looks like, well enough to produce new examples: a paragraph, a face, a melody. LLMs are generative: at each step they output a probability for every possible next token and sample one.

The line is blurry in practice: you can ask a generative LLM to classify an email by having it write "spam". But the question "is it learning to label, or to create?" still tells you a lot about how a model is trained and judged.

2. Where do its training signals come from?

  • Supervised learning: humans provide input–answer pairs (photo → "cat"). Accurate but expensive, so datasets stay relatively small. ImageNet (H1.2) is the classic example.
  • Self-supervised learning: the data provides its own answers. Hide the next word, a masked word, or part of an image, and predict it. Or add noise and learn to remove it. This is how LLMs and diffusion models can learn from billions of examples nobody labelled.
  • Reinforcement learning (RL): no answers at all, just a reward after trying something: points in a game, a passing test, a human thumbs-up. The model learns by trial and error. AlphaGo (2016) and today's reasoning models (H1.5) rely on it.

A modern chat model uses all three, in order: self-supervised pretraining on raw text, supervised fine-tuning on example answers, then RL from human or automatic feedback (M2.2, M3.1, M3.3; RL from scratch in RL.1).

A model learns to play chess only from wins and losses in games against itself. Which learning paradigm is that?

  1. Reinforcement learning
  2. Supervised learning
  3. Self-supervised learning
  4. It isn't learning; it's a hand-written expert system
There are no correct moves given, only a reward at the end of each game. Learning from rewards by trial and error is reinforcement learning, the approach behind AlphaZero (RL.6).

Architectures: the main families

The architecture is how a network's layers are wired. Each family builds in a different assumption about the data, called an inductive bias. A good assumption lets a model learn from less data; a weaker one needs more data but is more flexible. Watch the families branch off over time:

  • MLP (multi-layer perceptron, from 1986): layers where every unit connects to every unit in the next. No built-in assumption about the data. It's the "feed-forward" block inside every transformer (P3.1).
  • CNN (1989): assumes nearby pixels matter together and a pattern means the same thing anywhere. Great for images and spectrograms (P6.1, P6.2).
  • RNN / LSTM (1990s): assumes data arrives in order and keeps a running memory. Natural for sequences, but slow to train because steps run one after another (P6.3).
  • Transformer (2017): assumes very little; attention learns which positions matter for each other. Hungry for data, but scales superbly and trains in parallel. It now dominates text, and increasingly images, audio and video (M1.1).
  • Mixture of experts (an old idea from 1991, scaled up from 2017): replaces one big MLP block with many experts and a router. Not a separate family so much as a way to make transformers bigger without making each token more expensive (M5.3).
  • State-space models (S4, 2021; Mamba, 2023): recurrent-style layers designed to train in parallel, whose cost grows only linearly with sequence length, versus attention's square. Often mixed with attention layers in "hybrid" models (AR.3, AR.4).

Why do CNNs typically need less training data than transformers for small image tasks?

  1. CNNs have more weights
  2. Transformers can't process images at all
  3. CNNs use reinforcement learning
  4. CNNs build in assumptions about images (local patterns, the same pattern anywhere) that transformers must learn from data
That built-in assumption, the inductive bias, is a head start. With enough data, transformers learn such patterns themselves and often overtake CNNs (V1.1).

The generative families

Generative models face a hard task: produce something new that looks like it came from the real data. Five approaches dominate, and you'll meet each one in depth later.

  • Autoregressive models generate one piece at a time, each conditioned on everything so far: next token, next token, next token. This is how LLMs write. It also works for images and audio once they're turned into tokens (M1.5).
  • VAEs (variational autoencoders, 2013) squeeze data into a small "latent" code and learn to decode codes back into data. Pick a random code, decode it, and you get a new sample. Today they're often used as the compressor inside image generators (G1.1).
  • GANs (2014) pit a generator against a discriminator. They produced the first photo-realistic faces, but are notoriously unstable to train (G1.2).
  • Diffusion models (2015; practical from 2020) learn to remove a little noise at a time, then generate by starting from pure noise and denoising step by step. Since about 2021 they lead image generation and are central to video (G1.3, G1.4).
  • Flow matching (2022) learns a smooth path from noise straight to data, so generation needs fewer steps. Several leading image and video models now use it (G1.5).

These families aren't rivals in separate boxes. A typical 2025-era image generator uses a VAE to compress images, a transformer as its network, and diffusion or flow matching as its training objective (G1.6).

Explain like I'm 5

Think of AI as one big tree. The glowing trunk is the artificial neuron, plus the trick for teaching it (backprop). Everything grows out of that.

On the branches sit different animals, each good at one thing. The owl reading is a language model. The parrot singing makes speech and music. The chameleon painting makes pictures. The bat listening understands sounds, like speech recognition. The robot playing a board game learns from wins and losses: reinforcement learning.

They all drink from the same roots, so they can learn from each other.

Where it breaks: real branches don't merge, but AI families do. Today one model can read, listen, speak and draw, as if the owl, parrot and chameleon became a single animal.

How does a diffusion model generate an image?

  1. It writes the image one pixel at a time, left to right
  2. It starts from pure noise and removes a little noise at each step until an image appears
  3. A generator and a discriminator compete
  4. It looks up the closest image in its training set
Training teaches it to remove noise; generation runs that in reverse from random noise. Pixel-by-pixel is autoregressive; generator versus discriminator is a GAN.

Modalities, and the whole map

The last axis is the modality: the kind of data. Text (language models), images (classification, detection, generation), audio (speech recognition, speech synthesis, music), video (understanding and generation) and multimodal models that mix them.

Modalities used to have their own families: CNNs for images, RNNs for speech and text. Now one trick unifies them: turn everything into tokens. Text becomes word pieces; images become patches; audio becomes short chunks or codec tokens; video becomes space-time patches. Once data is a sequence of tokens, the same transformer can read, and generate, any of it. That's why the lanes merged after 2020, and why "multimodal" is now the norm for frontier models.

What lets one transformer handle text, images, audio and video?

  1. A separate transformer is hand-designed for each modality
  2. Images and audio are first described in words by a person
  3. Each modality is turned into a sequence of tokens (word pieces, image patches, audio chunks), which attention can process in the same way
  4. Transformers convert everything into pixels
Tokens are the common currency. Patches and audio tokens get embeddings just like words do (V1.1, A1.3, VD.1).

Check yourself

Which pairing of family and inductive bias is right?

  1. Transformer: assumes nearby pixels belong together
  2. CNN: assumes data arrives in time order
  3. RNN: assumes nothing about the data
  4. CNN: local patterns that mean the same thing wherever they appear
CNNs build in locality and "same pattern anywhere". RNNs assume order. Transformers assume the least and learn relationships with attention.

A model is trained to fill in randomly masked patches of photos, with no human labels. What is it?

  1. Self-supervised
  2. Supervised
  3. Reinforcement learning
  4. Not machine learning
The hidden patches are the targets, taken from the data itself. That's self-supervised learning, as in masked autoencoders (V1.3).

Which family is mainly generative?

  1. A CNN image classifier
  2. A spam filter
  3. A GAN
  4. A speech-to-text system
A GAN's generator creates new images. The other three map an input to a label or a transcript, which is discriminative.

From H1.5: where does mixture of experts sit on the map?

  1. It's a new modality, alongside text and images
  2. It's an architectural variation, usually inside transformers: a router sends each token to a few expert MLPs
  3. It's a learning paradigm, like reinforcement learning
  4. It's a type of generative model that replaces diffusion
MoE changes how the MLP blocks are wired, adding capacity without adding much compute per token. It's used in many large LLMs, such as Mixtral and DeepSeek-V3.

Key takeaways

  • Discriminative models label; generative models create (LLMs are generative).
  • Training signals: supervised (human labels), self-supervised (the data labels itself), reinforcement learning (rewards). Chat LLMs use all three.
  • Architectures: MLP (1986), CNN (1989), RNN/LSTM (1990s), Transformer (2017), plus MoE and state-space models. Each builds in a different inductive bias.
  • Generators: autoregressive, VAE, GAN, diffusion, flow matching, often combined in one system.
  • Turning every modality into tokens let transformers unify text, images, audio and video.
